Senior Project Concept & Proposal
ข้อเสนอโครงงาน Senior Project (เทคโนโลยีมีเดีย มจธ.)
ชื่อโครงงาน (Title) ระบบแพลตฟอร์มการเรียนรู้สื่อมัลติมีเดียเชิงโต้ตอบสำหรับนักศึกษาเทคโนโลยีมีเดีย (Interactive Learning Web Platform for Media Technology)
ที่มาและความสำคัญ ในปัจจุบันการเรียนรู้ทักษะด้าน Media Technology และ Web Programming จำเป็นต้องอาศัยการทดลองปฏิบัติจริง (Hands-on Practice) จึงมีแนวคิดที่จะพัฒนาเว็บแอปพลิเคชันที่รวบรวมสื่อการสอนแบบ Interactive Sandbox เพื่อให้ผู้เรียนสามารถเขียนโค้ดและเห็นผลลัพธ์แบบเรียลไทม์
วัตถุประสงค์
  • ออกแบบและพัฒนาระบบ Interactive Web Playground ที่รองรับการจำลองโครงสร้าง HTML5, CSS3, และ JavaScript
  • สร้างสื่อการสอนแบบ Gamification เพื่อประเมินผลทักษะการเขียนโปรแกรมของนักศึกษาอย่างเป็นระบบ
  • ประเมินความพึงพอใจและประสิทธิผลในการเรียนรู้ของนักศึกษาหลักสูตรเทคโนโลยีมีเดีย
เครื่องมือและเทคโนโลยี HTML5 Semantic Modern Vanilla CSS JavaScript ES6+ Node.js API Figma (UI/UX)
ผลที่คาดว่าจะได้รับ แพลตฟอร์มเว็บที่ใช้งานได้จริง เป็นสื่อการเรียนรู้ต้นแบบสำหรับภาควิชา และสามารถนำไปต่อยอดใช้ในการเรียนการสอนวิชาด้านเว็บและการเขียนโปรแกรมสื่อประสม
