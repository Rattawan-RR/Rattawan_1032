Senior Project Concept & Proposal
ข้อเสนอโครงงานปริญญานิพนธ์ / Senior Project Proposal (เทคโนโลยีมีเดีย มจธ.)
ชื่อโครงงาน (Title) ระบบประเมินความเสี่ยงของการเกิดต้อกระจกจากภาพดวงตาด้วยการประมวลผลภาพและการเรียนรู้เชิงลึก
(Cataract Risk Assessment System Using Image Processing and Deep Learning)
แนวคิดของโครงงาน (Concept) พัฒนาระบบด้วยภาษา Python ที่รับภาพดวงตาเข้าสู่กระบวนการประมวลผลภาพ ก่อนใช้โมเดล Deep Learning วิเคราะห์ลักษณะที่เกี่ยวข้องกับต้อกระจก จากนั้นแสดงผลการจำแนกภาพ ระดับความน่าสงสัย หรือผลการประเมินตามที่โมเดลได้รับการฝึกและตรวจสอบความถูกต้อง พร้อมแสดงคำแนะนำให้ผู้ใช้เข้ารับการตรวจจากจักษุแพทย์เมื่อเหมาะสม
ข้อสำคัญ / ข้อกำหนดข้อมูล: หากใช้เพียงภาพถ่ายดวงตาทั่วไป ระบบอาจไม่สามารถประเมินความเสี่ยงได้อย่างน่าเชื่อถือเท่าภาพตรวจเฉพาะทาง เช่น ภาพจากกล้อง Slit-lamp หรือภาพเลนส์ตาที่ใช้ในชุดข้อมูลทางการแพทย์ ดังนั้นควรกำหนดชนิดภาพและขอบเขตการประเมินให้ชัดเจนตั้งแต่เริ่มโครงงาน
1. ที่มาและความสำคัญ โรคต้อกระจกเป็นปัญหาด้านสุขภาพดวงตาที่ส่งผลต่อการมองเห็น โดยการตรวจประเมินจำเป็นต้องอาศัยการตรวจทางจักษุวิทยา ปัจจุบันเทคโนโลยี Deep Learning สามารถนำมาประยุกต์ใช้วิเคราะห์ภาพทางการแพทย์ เพื่อช่วยคัดกรองและจำแนกลักษณะที่เกี่ยวข้องกับต้อกระจกได้

โครงงานนี้จึงมีแนวคิดในการพัฒนาระบบประมวลผลภาพด้วยภาษา Python ร่วมกับโมเดล Deep Learning เพื่อวิเคราะห์ภาพดวงตาและประเมินระดับความน่าสงสัยของต้อกระจก พร้อมนำเสนอผลผ่านส่วนติดต่อผู้ใช้ที่เข้าใจง่าย เพื่อเป็นต้นแบบเครื่องมือสนับสนุนการคัดกรองเบื้องต้น
2. วัตถุประสงค์
  • เพื่อพัฒนาระบบประมวลผลภาพดวงตาด้วยเทคนิค Image Processing
  • เพื่อสร้างและทดสอบโมเดล Deep Learning สำหรับจำแนกภาพตามกลุ่มต้อกระจกและกลุ่มปกติ โดยใช้ข้อมูลที่มีป้ายกำกับอ้างอิงเหมาะสม
  • เพื่อพัฒนาหน้าเว็บแสดงผลการวิเคราะห์ภาพและค่าความเชื่อมั่นของโมเดล
  • เพื่อประเมินประสิทธิภาพของโมเดลและความพึงพอใจในการใช้งานระบบ
3. ขอบเขตของโครงงาน
  • ใช้ชุดข้อมูลภาพดวงตาที่มีป้ายกำกับสำหรับการฝึกและทดสอบโมเดล (ภาพตรวจเฉพาะทาง เช่น ภาพจากกล้อง Slit-lamp หรือภาพเลนส์ตาในชุดข้อมูลทางการแพทย์)
  • ปรับขนาดภาพ ปรับคุณภาพภาพ และเตรียมข้อมูลก่อนเข้าสู่โมเดล
  • ทดลองใช้โมเดล CNN เช่น ResNet หรือ EfficientNet ด้วยเทคนิค Transfer Learning
  • พัฒนาระบบต้นแบบสำหรับอัปโหลดภาพและแสดงผลการประเมิน
  • ทดสอบด้วยข้อมูลที่แยกออกจากชุดฝึก และวิเคราะห์ผลการจำแนก
4. เครื่องมือและเทคโนโลยี
Python OpenCV PyTorch / TensorFlow CNN (ResNet, EfficientNet) Google Colab Streamlit Figma
5. ผลที่คาดว่าจะได้รับ
  • ได้โมเดลต้นแบบสำหรับวิเคราะห์และจำแนกภาพที่เกี่ยวข้องกับต้อกระจก
  • ได้ระบบแสดงผลการวิเคราะห์ภาพผ่านเว็บแอปพลิเคชัน
  • ได้ผลการทดลองประสิทธิภาพของโมเดลจากตัวชี้วัดทาง Machine Learning
  • ได้ต้นแบบสื่อดิจิทัลที่สามารถนำไปศึกษาต่อยอดด้าน AI และเทคโนโลยีสุขภาพได้
